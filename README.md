# agentic-ai-lab

My build-in-public lab for a five-month agentic AI journey.

## Structure
- `week-00` … `week-16`: weekly exercises and experiments
- `notes/`: concept summaries and tool cards
- `tests/`: tests run in CI

## Setup
uv sync
cp .env.example .env   # add your keys

## Rules
- No graded assignments or course materials in this repo.
- No secrets: `.env` is git-ignored.
